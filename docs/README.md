# 🛠️ projet-structure-avancee

## Description Générale du Projet

Ce dépôt a été créé dans le cadre du mini-projet collaboratif Git des Fondamentaux du Développeur chez 3iL Ingénieurs.

L'objectif principal est de **maîtriser la gestion de version Git en équipe** et de **construire une arborescence rigoureuse** Nous nous concentrons également sur la création d'un `git log` clair, organisé et significatif en utilisant des conventions de commits strictes

Le projet est un exercice purement structurel et organisationnel. Le contenu des fichiers texte est libre.
